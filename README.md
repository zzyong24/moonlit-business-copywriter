# 月明·商业内容写作

围绕观众的具体处境和真实材料，规划中文口播、AI 工具实测与商业内容的表达。

## 你会得到什么

- 观众处境、关切和预期收益组成的内容简报
- 与真实任务和证据对应的内容角度
- 适用于口播或商业内容的表达建议

## 试着这样说

```text
用 moonlit-business-copywriter。我想讲这次 AI 工作流实测。先根据材料明确观众关切和能带走的东西，再帮我组织口播，没验证的部分保留未知。
```

## 安装与首次使用

将本仓库的完整目录交给支持本地 Skill 的 Agent 安装，保留 `SKILL.md` 与随附资源。已有同名版本时先检查差异；使用版本锁的工作区沿用自身升级机制。

让 Agent 安装：

```text
请安装这个 Skill：https://github.com/zzyong24/moonlit-business-copywriter
```

也可通过 Skills CLI 安装：

```bash
npx skills add zzyong24/moonlit-business-copywriter
```

## 配置与依赖

需要当前定位、目标受众及真实案例或测试材料。内容原则与表达参考随本 Skill 提供；需要新增对标研究时配合 moonlit-benchmark-research。当前文风和账号语境面向月明水清深。

## 数据与使用边界

文本由当前 Agent 处理，研究工具按任务使用。本 Skill 不凭空生成亲历或成交证据，输出内容不代表已经完成拍摄、制作或发布。

## 配套 Skill

[benchmark-research](https://github.com/zzyong24/moonlit-benchmark-research)

## 详细说明

执行流程与资源导航见 [SKILL.md](SKILL.md)。安装检查不代表真实业务验收；需要外部服务、账号登录或付费生成的步骤，应在使用者自己的环境中验证。
